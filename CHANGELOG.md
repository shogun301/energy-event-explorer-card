# Changelog

All notable changes are documented here. This project follows Semantic Versioning.

## [Unreleased]

## [0.1.2] - 2026-08-31

- Rewrote public and card-picker descriptions around event timing, duration,
  associated energy, and explicit missing-data reporting.

## [0.1.1] - 2026-08-31

- Added an original Energy Event Explorer logo with SVG source and 256/512-pixel PNG exports.

## [0.1.0] - 2026-08-30

- Initial provider-neutral event rule engine.
- Export/SOC-headroom, discharge/export, undercharge, operating-plan, plan-change, and tariff-window rules.
- Fail-closed handling for missing required observations.
- Event duration and associated exported-energy totals.
- Shared range selector and responsive site/battery history card.
- Synthetic fixtures, deterministic build, privacy scan, and HACS validation workflow.
